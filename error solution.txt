Practical 1 – Uber Fare Prediction
Algorithms: Linear Regression and Random Forest Regression.

Error 1: Python was not found
Error
Python was not found; run without arguments to install from the Microsoft Store.
Cause:

Windows could not identify the python command.

Python was installed, but the command was not properly configured for Code Runner.

Solution:

We changed the Python command in VS Code settings.json.

Previously:

"python": "python -u"

Changed to:

"python": "py -3.14 -u"

This allowed Code Runner to execute Python 3.14.

Error 2: Code Runner exited with code 9009
Error
[Done] exited with code=9009
Cause:

Code Runner could not locate or execute the configured Python command.

Solution:

We corrected the Python interpreter command in settings.json:

"python": "py -3.14 -u"

After correcting it, the test program executed successfully with exit code 0.

Error 3: SyntaxError due to merged statements
Error
Incorrect code:

p1 = lr.predict(X_test)lr = LinearRegression()

Cause:

Two Python statements were accidentally joined on the same line without a separator.

Solution:

Write each statement separately:

lr = LinearRegression()

lr.fit(X_train, y_train)

p1 = lr.predict(X_test)

Error 4: Incorrect assignment statement
Error
Incorrect code:

p2 = rf.predict(X_test) = RandomForestRegressor()

Cause:

The model creation and prediction statements were written incorrectly.

Solution:

First create the model, then train it, and finally make predictions.

rf = RandomForestRegressor()

rf.fit(X_train, y_train)

p2 = rf.predict(X_test)

Error 5: Random Forest model not initialized
Error
NameError: name 'rf' is not defined
Cause:

The variable rf was used before creating the Random Forest model.

Solution:

Initialize the model before using it:

rf = RandomForestRegressor(random_state=42)

Then train it:

rf.fit(X_train, y_train)

Error 6: Dataset file not found
Possible error:

FileNotFoundError: [Errno 2] No such file or directory
Cause:

The program could not find uber.csv in the location specified in pd.read_csv().

Solution:

Keep the dataset in the correct folder and use a path relative to the Python file:

from pathlib import Path

dataset_path = Path(__file__).resolve().parent / "uber.csv"

df = pd.read_csv(dataset_path)

_pywrap_tensorflow_internal.pyd

To check TensorFlow:

Error 5: Accuracy was high, but the model did not identify churn customers
Your output was:

Accuracy: 0.92

Confusion Matrix:
[[92  0]
 [ 8  0]]
Cause:

The model predicted every test record as Not Exited. The dataset had an imbalance between the two classes.

This was a model-performance issue, not a Python execution error.

Solution:

We identified the need for techniques such as class weighting and prediction-threshold tuning.

For example, class weighting can be added during training:

model.fit(
    X_train,
    y_train,
    epochs=50,
    batch_size=32,
    class_weight={0: 1, 1: 3}
)

The weights should be selected based on the training data and evaluation results.

Practical 4 – Diabetes Prediction using KNN
Algorithm: K-Nearest Neighbors (KNN).

Error 1: Dataset file not found
Error
Initially, the program searched for:

D:\Practicals\ML\Practical3\dataset\diabetes.csv
But your dataset was stored in Practical 4.

Cause:

The Python script was using the wrong folder path.

Solution:

We used Path(__file__) to automatically locate the dataset relative to the script.

from pathlib import Path

dataset_path = (
    Path(__file__).resolve().parent
    / "dataset"
    / "diabetes.csv"
)

df = pd.read_csv(dataset_path)

Error 2: Running the wrong practical file
You initially ran the script from Practical 3 instead of Practical 4.

Solution:

Execute the correct file:

"D:\Practicals\ML\Practical2\.venv\Scripts\python.exe" -u "D:\Practicals\ML\Practical4\KNN_Diabetes.py"
Error 3: Missing feature scaling
This was not a runtime error, but an important ML implementation issue.

Cause:

KNN calculates distances between data points. Features with larger numerical ranges can influence the distance more strongly.

Solution:

We used StandardScaler:

scaler = StandardScaler()

X_train = scaler.fit_transform(X_train)

X_test = scaler.transform(X_test)

Important: Always use fit_transform() on training data and only transform() on testing data to avoid data leakage.
